# User Flows

This document describes the main user journeys of the Nevyrion Learning Academic MVP.

## Student Journey

Course Discovery
→ Course Details
→ Authentication
→ Enrollment
→ Learning
→ Progress Tracking
→ Quiz
→ Course Completion
→ Certificate

## Instructor Journey

Login
→ Instructor Dashboard
→ Create Course
→ Submit Course
→ Admin Review
→ Approval
→ Course Publication

## Admin Journey

Login
→ Admin Dashboard
→ Review Submitted Course
→ Approve / Reject
→ Course Publication

## Learning Path Journey

Explore Learning Path
→ Enroll
→ Follow Steps
→ Complete Courses
→ Complete Learning Path
